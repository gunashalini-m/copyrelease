Introis Invoice Generator
=========================

Do NOT open public/index.html. That is source, not the app.

Open this file (in the folder root):
  Introis-Invoice-Generator.html

Using Visual Studio Code
------------------------
1. File → Open Folder…
2. Choose the unzipped folder
   (copyrelease-cursor-invoice-generator-16f6)
3. In the left file list, click Introis-Invoice-Generator.html
   (top of the folder, not inside public/)
4. Right-click that file → Open with Live Server
   If you do not see that: Extensions, install "Live Server" by Ritwick Dey,
   then right-click again.
5. A browser tab should open with the full styled invoice form.

Or right-click Introis-Invoice-Generator.html → Reveal in Finder →
double-click to open in Chrome.

You do not need npm for this.
